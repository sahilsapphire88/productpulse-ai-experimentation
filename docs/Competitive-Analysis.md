# Competitive Analysis — ExperimentLab

> **ILLUSTRATIVE** — This analysis is based on public product knowledge. No unsupported claims are made about specific competitors.

## Categories Analyzed

| Category | Examples (illustrative) | What They Provide |
|----------|------------------------|-------------------|
| Product analytics platforms | Amplitude, Mixpanel, PostHog | User behavior analytics, funnels, retention |
| A/B testing platforms | Optimizely, VWO, Statsig | Experimentation infrastructure, feature flags, statistical results |
| Feature flag platforms | LaunchDarkly, Split | Feature rollout, targeting, kill switches |
| AI analytics tools | Various LLM observability platforms | Model performance, token cost, latency |
| Spreadsheet-based experimentation | Google Sheets, Excel | Manual experiment tracking, ad-hoc analysis |

## Identified Gap

Existing tools provide analytics **or** experimentation infrastructure. ExperimentLab focuses on the **PM decision-making workflow** from hypothesis → experiment → analysis → product decision, with AI cost analysis as a core differentiator.

## Differentiators

1. **AI-generated hypothesis** — structured starting point, clearly labelled.
2. **AI cost analysis** — incremental revenue vs incremental AI cost, ROI.
3. **Transparent decision engine** — SHIP / ITERATE / KILL with explicit reasoning.
4. **What-if simulator** — dynamic scenario planning.
5. **Synthetic data labeling** — all data clearly marked as demo/illustrative.

## Limitations

- No real analytics integrations (MVP).
- No feature flag integrations (MVP).
- Decision engine uses simplified rules.
