# MoSCoW Prioritization — ExperimentLab

> **ILLUSTRATIVE** — Prioritization is for portfolio demonstration purposes.

## Must Have (MVP — Phase 1)

- Experiment creation form (name, problem, target users, baseline, expected improvement, duration, AI cost)
- AI hypothesis generator (structured, labelled AI-generated)
- Experiment designer (A/B test, variants, traffic allocation, metrics, guardrails)
- Synthetic dataset generator (deterministic, seeded, labelled synthetic)
- Statistical analysis engine (conversion, lift, CI, significance from data)
- Decision engine (SHIP / ITERATE / KILL with reasoning)
- All data labelled synthetic / demo

## Should Have (Phase 2)

- AI cost analysis (incremental revenue vs cost, ROI)
- What-if simulator (dynamic scenario planning)
- Experiment dashboard (active experiments, health stats)
- AI assistant (data-grounded Q&A)

## Could Have (Phase 3)

- Real analytics integrations (Amplitude, Mixpanel)
- Feature flag integrations (LaunchDarkly, Split)
- Experiment history / decision log persistence
- Team collaboration (shared experiment library)
- Export to PDF/CSV

## Won't Have (MVP)

- Real customer data
- Real statistical results from production experiments
- User authentication / SSO
- Mobile app
- Enterprise SSO/SAML
