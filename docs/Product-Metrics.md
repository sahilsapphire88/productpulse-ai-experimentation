# Product Metrics — ExperimentLab

## North Star Metric

**Validated Product Decisions**

The number of product decisions (Ship / Iterate / Kill) made with clear statistical and economic evidence, per month.

## Metric Definition vs Demo Values

- **Product metric definitions** are real product governance artifacts (formula, owner, target).
- **Demo metric values** are synthetic / illustrative and do not represent actual product performance.

All dashboard numbers in the application are labelled **Demo / Synthetic Data**.
