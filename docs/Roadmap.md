# Roadmap — ExperimentLab

## Phase 1 — MVP

- Experiment creation (name, problem, target users, baseline, expected improvement, duration, AI cost)
- Hypothesis generation (AI-generated, structured, labelled)
- A/B test configuration (variants, traffic allocation, metrics, guardrails)
- Synthetic dataset generation (deterministic, seeded)
- Statistical analysis (lift, CI, significance from data)
- Decision engine (SHIP / ITERATE / KILL with reasoning)
- Ethical data labelling (Synthetic / Demo Data)

## Phase 2

- What-if simulator (dynamic conversion, cost, traffic, duration scenarios)
- AI assistant (data-grounded Q&A about the current experiment)
- AI cost analysis (incremental revenue vs cost, ROI, cost per conversion)
- Advanced analytics (guardrail monitoring, trend charts)

## Phase 3

- Real analytics integrations (Amplitude, Mixpanel, PostHog)
- Feature flag integrations (LaunchDarkly, Split, Statsig)
- Experiment history and persistence
- Team collaboration (shared experiment library, comments)
- Export to PDF/CSV
